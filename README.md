## 📖 Description
**Warping Wonders** makes teleporting more immersive by using items you already know. Teleport to a Lodestone with a linked **Compass**, back to your spawn point with a **Clock**, or to your last death location with a **Recovery Compass**. Invite friends to you with the new **Portal Horn**, a TPA replacement, and build a network of **Waypoint Hubs** to travel between your favorite places.

All teleports work across dimensions, and your mounts and leashed mobs (even boats) can come along for the ride.

<br>

## 🔎 Content Overview (Wiki)
Want to know how each teleport works or how to set up your Waypoint network? It's all in our **[Wiki](https://wiki.explorerseden.eu/en/Warping_Wonders/home)**:
- 🧭 **Teleport Items**: Compass, Recovery Compass and Clock, including their craftable variants
- 📯 **Portal Horn**: invite another player to teleport to you
- 🗿 **[Waypoint Hubs](https://wiki.explorerseden.eu/en/Warping_Wonders/Waypoint_Hub)**: lots of variants to match any build, with custom names, icons, colors, descriptions and private or trusted access
- ⚙️ **Administration**: experience costs, break chances and Waypoint Hub settings in the config menu (`/function warping_wonders`)

## 🛠️ Technical Gibberish
Admins can teleport to and edit any Waypoint Hub, no matter who owns it. The admin tag is added automatically when you open the config menu, or you can set it manually with `/tag <player> add wawo.admin`.

This data pack also works as the **required** resource pack. Just put the same file into your `resourcepacks` folder and enable it in game so the textures show up properly.

_(Not needed for the auto-converted mod versions in Single-Player.)_

**PaperMC users:** set the `paper.maxChatCommandInputSize` property to a value between 512 and 1024 (see the [PaperMC Docs](https://docs.papermc.io/paper/reference/system-properties/#papermaxchatcommandinputsize)) and enable `allow-non-player-entities-on-scoreboards` in your Paper config.
