## 📖 Description
**Warping Wonders** allows for a more immersive player teleportation utilizing already existing items. Using a compass which is linked to a lodestone players can teleport back to the lodestone. A clock teleports players back to their spawnpoint (bed, respawn anchor) and the recovery compass can bring players back to their last death location. The latter two always get consumed when using them. In addition to that Portal Horns can be crafted which function as a TPA replacement. The latest addition to the data pack is a Waypoint Hub system which lets players set up a network of points of interest where they can teleport to. All teleport actions function across all dimensions. Ridden Entites (Camel, Strider, Donkey, Mule, Horse, Llama and Horses) as well as leashed Entities (including Boats) will be teleported alongside players.

**With v2.5+ Admins/OPs can configure almost anything in-game using config menus.**
<details>
<summary>Command to open the Config Menu</summary>

```
/function warping_wonders
```

</details>


<details>
<summary>Admin Tag</summary>
The Admin Tag allows for teleporting and editing any Waypoint regardless of being the owner or not.
  
Will either be set automatically when opening the Config Menu or can be set with:

```
/tag <playername> add/remove wawo.admin
```

</details>



## 🧭 Item Overview
<details>
<summary>Compass</summary>
Compasses can teleport you to their linked Lodestones, and several additional variants can also be crafted.
</details>
<details>
<summary>Recovery Compass</summary>
You can use a Recovery Compass to teleport to where you last died, and there are also a bunch of other variants you can craft.
</details>
<details>
<summary>Clock</summary>
Using a Clock teleports you back to your respawn point — usually your Bed or Respawn Anchor.
</details>
<details>
<summary>Portal Horn</summary>
Tooting a Portal Horn brings up a menu to invite another player to teleport to you. They’ll get a chat message where they can choose to accept.
</details>
<details>
<summary>Waypoint Hub</summary>
Waypoint Hubs can be crafted and placed to create fixed teleport locations that connect to other Waypoint Hubs. Multiple variants are available, each crafted with a different base block so they can blend seamlessly into any build.
<br><br>
  
- Menus only display destinations the player can access (public or their own private waypoints).
- Pickaxes are the default tool for mining/breaking Waypoint Hubs.
- Private Waypoints display a lock icon above their name.
- Left- or right-clicking the icon of a Waypoint Hub you placed with a renamed Name Tag changes its name.
- Left- or right-clicking with a renamed Book adds/changes a description for the Waypoint Hub to the menu tooltip lore.
- Left- or right-clicking with a renamed Paper grants/revokes access permission for a player to teleport to the Waypoint regardless of it being locked ("trust <playername> / "untrust <playername>")
- Left- or right-clicking with a Dye changes the waypoint’s text color.
- Left- or right-clicking with a Waypoint Lock toggles its accessibility (private/public).
- Left-clicking the icon without an item (Name Tag, Dye, etc.) cycles through available icons/heads.
- Right-clicking the icon without an item opens the waypoint menu.
- Placing a Wool block beneath the hub disables teleportation announcements for that hub.
</details>
<details>
<summary>Waypoint Lock</summary>
Waypoint Locks can be crafted to switch a Waypoint Hub’s visibility between private and public.
</details>

## 🛠️ How to, Instructions & Commands
The datapack usually just needs to be installed. There is nothing else you have to do. It just works out of the box.

For **PaperMC users**, it is recommended to set the `paper.maxChatCommandInputSize` property to a value between 512 and 1024. More information can be found in the [PaperMC Docs](https://docs.papermc.io/paper/reference/system-properties/#papermaxchatcommandinputsize). Also make sure to have `allow-non-player-entities-on-scoreboards` enabled in your paper configs.

**The data pack version also double functions as a resource pack. So in order to be able to see them, just place the data pack .zip also in your resource folder and activate it like any other resource pack.**
